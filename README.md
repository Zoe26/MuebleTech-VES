# MuebleTech VES

## Descripción del proyecto

MuebleTech VES es un proyecto de desarrollo Back End orientado a la gestión de un catálogo de muebles industriales del Parque Industrial de Villa El Salvador, Lima, Perú.

El sistema permitirá administrar productos, categorías, precios y disponibilidad mediante una API REST desarrollada con Python y Flask.

## Objetivo general

Desarrollar una API REST que permita gestionar la información de los muebles industriales mediante operaciones CRUD, utilizando Python, Flask y PostgreSQL, e incorporando mecanismos de autenticación y seguridad.

## Tecnologías

- Python 3.14.8
- Flask 3.1.3
- PostgreSQL (pendiente de integración)
- SQLAlchemy (pendiente)
- JWT (pendiente)
- Git y GitHub (pendientes de configuración)

## Funcionalidades previstas

- Registrar muebles.
- Consultar el catálogo de productos.
- Actualizar información de muebles.
- Eliminar productos.
- Administrar categorías.
- Autenticar usuarios mediante JWT.
- Almacenar información en PostgreSQL.
